Nạp Dữ Liệu Đối Chiếu Tạp Chí (SCImago / Scopus / ABDC)

Tải file CSV từ SCImago Journal Rank (scimagojr.com) hoặc file Excel/CSV danh mục tạp chí của bạn (cần có cột ISSN hoặc Title và cột SJR Best Quartile / Quartile). Dữ liệu sẽ được lưu trên trình duyệt để tự động đối chiếu cho mọi lần tìm kiếm sau.

Tự Động Tóm Tắt & Lập Ma Trận Tài Liệu (Literature Matrix)

Chọn nhanh 1 trong 2 chế độ linh hoạt bên dưới để phân tích Abstract của các bài đã tick chọn ở Tab 1 thành 4 cột chuẩn (Tóm tắt, Phương pháp & Mẫu dữ liệu, Kết quả chính, Khoảng trống nghiên cứu). Bạn có thể chuyển chế độ và chạy lại bất cứ lúc nào.

Miễn Phí (Không cần API Key hay Email)

Không cần nhập API Key hay Email. Tự động tách 4 nội dung trọng tâm từ Abstract OpenAlex và dịch nhanh sang tiếng Việt (hỗ trợ chạy qua server.py hoặc trực tiếp trên GitHub Pages).

Cấu Hình AI Chuyên Sâu & Dữ Liệu (Lưu cục bộ trên trình duyệt)

API Key chỉ lưu trong localStorage trên máy của bạn, không gửi đi bất kỳ server trung gian nào ngoài nhà cung cấp AI bạn chọn.

Gợi ý tạo Gemini API Key miễn phí: Truy cập aistudio.google.com/apikey để tạo khóa Google Gemini miễn phí trong 30 giây, dùng mượt với gemini-3.8-flash hoặc dòng Gemini 4 mới nhất.
